## Curation workflow

1. **Browse**: Click each search link above, listen to 3-5 candidates per track
2. **Select**: Pick 1 per track slot (12 total)
3. **Download**: Save WAV files to `Assets/_Project/Audio/Music/` with naming:
   - `track_01_first_lap.wav`
   - `track_02_curves_101.wav`
   - `track_03_chicane_sprint.wav`
   - `track_04_neon_sweep.wav`
   - `track_05_hairpin_highway.wav`
   - `track_06_slipstream.wav`
   - `track_07_maze_run.wav`
   - `track_08_final_check.wav`
   - `track_09_daily_track.wav`
   - `menu_theme.wav`
   - `race_complete.wav`
   - `race_failed.wav`
4. **Record attribution**: For CC-BY tracks, add to `CREDITS.md`
5. **Edit for looping**: Open in Audacity, trim to 2-4 min, apply 50ms crossfade at loop point
6. **Integrate**: Add AudioSource + MusicPlayer component, assign clips to tracks
